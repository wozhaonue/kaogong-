本地配置面板

这个页面会把 Supabase 配置写入当前站点同源的浏览器 localStorage，供 `policy-codex`、`map`、`flora`、`chronicles` 4 个工具页直接读取。

使用说明

  1. 先在 Supabase 中创建项目，并开启 Email OTP 登录。
  2. 把 `policy-codex-schema.sql` 和 `tool-documents-schema.sql` 执行到你的项目里。
  3. 在本页填写 URL 和 anon key 后保存。
  4. 回到各工具页刷新，即可看到“连接云同步”入口变为可用。

这个页面只影响当前浏览器和当前域名，不会把密钥提交回仓库，也不会影响其他设备。
